# Планер Ильи

Личный веб-планер для iPhone в стиле old money — тёмно-синий, пыльно-голубой, зелёный и слоновая кость.

**Разделы:**
- **Сегодня** — ближайшая встреча, мой день, просроченное, завтра, платежи на неделе, проекты в работе.
- **Работа** — рабочие задачи (с проектами, подзадачами, повторами), встречи и созвоны, проекты с прогрессом и дедлайнами.
- **Дела** — личные и домашние дела: сегодня / неделя / позже / готово.
- **Расходы** — записи по категориям, сравнение с прошлым месяцем, бюджет с лимитами, регулярные платежи (отметка «Оплатил» сама записывает расход), выгрузка в Excel.
- **Здоровье** — счётчик калорий со сканером штрихкодов (база Open Food Facts, свои продукты запоминаются — дальше вводится только граммовка), норма КБЖУ по методике тренера (на сухую массу тела), вес и % жира с весов Picooc и шаги — через «Здоровье» iPhone и команду в «Командах», оценка % жира по фото (Claude API, свой ключ), по обхватам или на глаз.
- **Аниме** (`anime/`) — где остановился в каждом аниме: сезон, серия, минута по истории AniLiberty, расписание, подборка, статистика. Это встроенная версия приложения [anime-progress](https://github.com/iluashakapusta/anime-progress) в стиле планера; на главном экране — карточка «Смотрю».
- **Ещё** — календарь, заметки, итоги года, настройки и резервная копия.

- Все данные хранятся **только на устройстве** (localStorage), никуда не отправляются.
- Работает офлайн (service worker), устанавливается на экран «Домой».
- Без сборки: чистые HTML, CSS и JS-модули. В `js/vendor` лежат готовые сторонние библиотеки (распознавание штрихкодов ZXing и Anthropic SDK, лицензии MIT). Чтобы посмотреть, как всё работает, — «Настройки → Заполнить примером».
